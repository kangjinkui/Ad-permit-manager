# 광고물 허가·신고 통합관리 시스템 구축 사업 추진 결과

## 사업개요

❍ **추진기간 :** 2026. 3. (약 1개월)

❍ **소요예산 :** 비예산 (AI 코딩 도구 자체 활용)

❍ **주요내용**
  - 엑셀 기반으로 분산 관리되던 광고물 허가·신고 대장을 웹 시스템으로 통합 구축
  - AI 코딩 도구(Claude Code)를 활용한 비예산 자체 개발로 신속한 시스템 구현

---

## 주요개선사항

| 구분 | 개선 전 | 개선 후 |
|------|---------|---------|
| **관리방식** | 엑셀 파일 개별 관리 (버전 혼재, 공유 불가) | 웹 기반 통합 관리 (실시간 다중 접속) |
| **검색·조회** | 파일 열람 후 수동 검색 | 허가번호·주소·상태 등 다중 조건 필터 즉시 검색 |
| **이력관리** | 변경이력 추적 불가 | 상태 변경 이력 자동 기록 및 타임라인 시각화 |
| **데이터 입력** | 건별 수동 입력 | 기존 엑셀 파일 일괄 업로드(대량 처리) 지원 |
| **접근 보안** | 파일 공유로 보안 취약 | 청 내부(@gangnam.go.kr) 계정 전용 인증 |
| **통계현황** | 별도 집계 작업 필요 | 대시보드에서 허가 현황 통계 실시간 제공 |

---

## 세부추진실적

> ※ 2개 이상 부서가 추진시 부서별 추진사항 구분하여 작성

❍ **시스템 기반 구축**
  - Supabase 기반 데이터베이스 설계 및 구축 (허가 대장, 변경이력, 사용자 테이블)
  - 행 수준 보안(RLS) 적용으로 인증된 내부 직원만 데이터 접근 허용
  - 강남구청 내부 이메일 도메인(@gangnam.go.kr) 한정 매직링크 로그인 구현

❍ **핵심 기능 개발**
  - 허가 목록 조회·검색·필터링 (허가번호, 주소, 업체명, 처리상태 등)
  - 신규 허가 등록 및 상태 변경 처리 (접수→검토→허가/반려)
  - 변경이력 자동 저장 및 타임라인 시각화 (누가 언제 어떤 처리를 했는지 추적)

❍ **편의기능 및 관리자 기능**
  - 기존 엑셀 대장 데이터 일괄 업로드 기능 (기존 데이터 마이그레이션 지원)
  - 실시간 허가 현황 대시보드 (건수·상태별 통계)
  - 관리자 사용자 계정 관리 기능
